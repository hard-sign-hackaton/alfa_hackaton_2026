## Извлечение данных из аналитических материалов

Проводится с помощью скрипта `extract_pdf.py`.
В данный момент он умеет преобразовывать PDF в Markdown и повторно парсить таблицы с более высоким качеством.
В итоге данные сохраняются в формате `JSON`, пока что сохраняются только текст и таблицы.
В дальнейшем планируется дополнительный анализ изображений с графиками с последующим сохранением.
