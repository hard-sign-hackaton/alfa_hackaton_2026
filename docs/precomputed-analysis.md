# Предварительный расчёт разборов

Профили группируют компании по ОКВЭД, но разбор рассчитывается отдельно для
каждой компании: платёжные связи и другие показатели внутри профиля различаются.
Для быстрого открытия карточек полный результат сохраняется в
`news_company_links.analysis_result`, включая основания, найденные фрагменты,
выводы, ограничения, короткий ответ и классификацию.

Обрабатываются активные релевантные связи. Полный перебор всех новостей и
компаний не выполняется. Готовые разборы переиспользуются; отсутствующая краткая
сводка дополняется без повторного исследования. Подготовка одной публикации
переиспользуется между компаниями. Статус `insufficient_data` — завершённый
разбор с явно указанными ограничениями, а не ошибка или выдуманный вывод.

```powershell
docker compose exec web python /app/scripts/precompute_analyses.py --dry-run
docker compose exec web python /app/scripts/precompute_analyses.py --workers 3
```

Нужен рабочий ключ моделей. Одновременно выполняется до трёх исследований
(параметр `--workers` допускает 1–4); по умолчанию до двух попыток на пару.
Повторный запуск продолжает недостающие результаты. Запись каждого результата
выполняется с проверкой актуальности исходной новости и профиля компании.
Прогресс и безопасная телеметрия сохраняются в `WEB_RUNTIME_DIR/precompute/report.json`.

После обработки обновите переносимый SQL-набор:

```powershell
python scripts/export_startup_data.py --news-database alfa_news
```

Укажите фактическое имя базы. Полные результаты входят в `database/seeds/04_links.sql`.
`manifest.json` содержит количества строк, контрольные суммы и `analysis_coverage`:
сколько активных пар имеет анализ и краткий ответ. После восстановления на новом
компьютере открытие этих разборов не требует LLM. Чат и обновление анализа
по-прежнему обращаются к моделям. Новости без релевантной связи не получают
чужой или общий разбор, выданный за персональный.
